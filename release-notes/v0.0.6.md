## codegraphV v0.0.6: MCP sessions stay connected, and upgrades reach them

codegraphV is a **full rewrite in Rust** of
[CodeGraph](https://github.com/colbymchenry/codegraph) by **Colby McHenry** (MIT). The design,
graph model, MCP tools, extractors and resolvers are his. This release fixes the connection
problems behind "codegraphV failed to connect" on Windows, and makes the v0.0.5 upgrade
hand-off work in practice.

### Fixes

- **On Windows, an agent session no longer loses codegraphV after a few seconds idle.** The
  background engine dropped any session that sent nothing for 3 seconds. Claude Code then
  showed the server as failed until you reconnected it. Sessions now stay connected however
  long they sit idle.
- **Open sessions really do move to a new version after `codegraphV upgrade`.** v0.0.5 added
  this, but on Windows the 3-second drop broke it, and a session whose connection dropped
  could not find its way back to an engine that was still running. Both are fixed: the next
  call after an upgrade is answered by the new version on the same connection.
- **`codegraphV upgrade` on Windows no longer fails when it runs twice while a session stays
  open.** The second upgrade stopped with "Cannot create a file when that file already
  exists", because the copy the first upgrade moved aside was still in use. This fix is in the
  installer script, so it applies to every upgrade from now on.

### Upgrade

```bash
codegraphV upgrade
```

Sessions running v0.0.5 or older need one last reconnect after this upgrade
(`/mcp reconnect all` in Claude Code); from v0.0.6 on, upgrades reach open sessions by
themselves. No re-index is needed.

### Install

```powershell
# Windows
irm https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.ps1 | iex
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.sh | sh
```

Then run `codegraphV install`, or `codegraphV migrate` if you used the original codegraph.
In each new project, run `codegraphV init`.

### Known gaps

- The binary is about 74 MB.
- The browser viewer is a preview behind `CODEGRAPHV_UI=1`, and it lacks some of the
  original's views.
- There is no npm package and no JavaScript library API.
- The CLI answers from the index as it is, like the original's CLI. While an agent session
  runs, its server keeps the index current; otherwise run `codegraphV sync` after editing.

Every archive is listed in `SHA256SUMS`.
