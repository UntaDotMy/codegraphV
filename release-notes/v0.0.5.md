## codegraphV v0.0.5: upgrades reach open agent sessions without a reconnect

codegraphV is a **full rewrite in Rust** of
[CodeGraph](https://github.com/colbymchenry/codegraph) by **Colby McHenry** (MIT). The design,
graph model, MCP tools, extractors and resolvers are his. This release makes upgrading smooth
for agents that are already running.

### Highlights

- **Open agent sessions move to the new version on their own.** After `codegraphV upgrade`,
  each open Claude Code, Cursor, Codex or opencode session keeps its MCP connection, and its
  next codegraphV call is answered by the new version. You no longer need to reconnect the
  server or start a new session. This works for upgrades *from* v0.0.5 onward; sessions still
  running v0.0.4 or older need one last reconnect (`/mcp reconnect all` in Claude Code).
- **A new session starts even while an older version is still running.** Before, if another
  session on the same project was still using an older codegraphV, a new session failed to
  connect. It now starts and answers on its own.

### Details

- The agent is told the tool list may have changed after a switch, so it picks up new tools
  without a reconnect.
- A request sent while the switch happens is answered once, by the new version.
- If the new version keeps stopping before it answers anything, the session gives up after a
  few tries instead of restarting it forever; reconnect the server after fixing the install.
- The server's startup instructions are read by the agent when it connects, so instruction
  changes in a new version still show up in the next session.

### Upgrade

```bash
codegraphV upgrade
```

No re-index is needed.

### Install

```powershell
# Windows
irm https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.ps1 | iex
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.sh | sh
```

Then run `codegraphV install`, or `codegraphV migrate` if you used the original codegraph.
In each new project, run `codegraphV init`.

### Known gaps

- The binary is about 74 MB.
- The browser viewer is a preview behind `CODEGRAPHV_UI=1`, and it lacks some of the
  original's views.
- There is no npm package and no JavaScript library API.
- The CLI answers from the index as it is, like the original's CLI. While an agent session
  runs, its server keeps the index current; otherwise run `codegraphV sync` after editing.

Every archive is listed in `SHA256SUMS`.
