## codegraph v0.0.1: the Rust rewrite

This is the first release of a **full rewrite in Rust** of
[CodeGraph](https://github.com/colbymchenry/codegraph) by **Colby McHenry** (MIT). The design,
graph model, MCP tools, extractors and resolvers are his. This release ports the TypeScript
engine (v1.6.2) to one native executable and checks it against the original.

### Highlights

- **One native binary** for Windows x64, Linux x64, macOS arm64 and macOS x64. You don't need
  Node.js or npm.
- **The same graph as the original:** on serde_json, tokio, this repo and one public repo for
  each of 15 languages, the Rust engine builds identical files, nodes and edges.
- **Faster answers:** a CLI explore query takes 37–57 ms against 1.1–2.0 s for the TypeScript
  CLI, with 10–24 MB of memory instead of 190–330 MB.
- **Indexing:** 1.8–2.6× faster on small and medium repos. **About 5% slower in wall time on
  a large repo** (54.9 s against 52.4 s on 1869 files), while using half the CPU time and
  less than a third of the memory.
- **The same agent setup:** `codegraph install` for Claude Code, Cursor, Codex, opencode,
  Gemini, Kiro, Hermes, Antigravity and GitHub Copilot, including the Claude prompt hook.
- **Auto-sync:** edits made while no agent session was running are picked up when the next
  session starts.
- **`codegraph upgrade`, an update notice, and `codegraph uninstall`,** which also removes the
  binary (`--keep-cli` to keep it).
- **No telemetry:** the binary sends nothing. The only request is a once-a-day release check,
  which you can turn off with `CODEGRAPH_NO_UPDATE_CHECK=1`.

### Install

```powershell
# Windows
irm https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.ps1 | iex
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.sh | sh
```

Then run `codegraph install` and, in each project, `codegraph init`. If you have the npm
version, run `npm rm -g @colbymchenry/codegraph` first, then `codegraph install --refresh`.

### Known gaps

- The binary is about 74 MB.
- The browser viewer is a preview behind `CODEGRAPH_UI=1`, and it lacks some of the
  original's views.
- There is no npm package and no JavaScript library API.
- `codegraph init` does not offer to index other repositories it finds under the folder.

The full benchmark, its method and its raw results are in the README and in
`docs/benchmarks/rust-v0.0.1/`. Every archive is listed in `SHA256SUMS`.
