## codegraphV v0.0.4: agents get the full MCP instructions

codegraphV is a **full rewrite in Rust** of
[CodeGraph](https://github.com/colbymchenry/codegraph) by **Colby McHenry** (MIT). The design,
graph model, MCP tools, extractors and resolvers are his. This release fixes the guidance the
MCP server gives agents when they connect.

### Fixes

- **Claude Code now receives the whole server instructions.** Claude Code cuts the text an MCP
  server sends at startup to 4096 characters; codegraphV sent about 6800, so agents never saw
  the end of it, including when to stop calling codegraphV on a project that isn't indexed. The
  instructions are now about 3200 characters, with room left for the update notice.
- **The instructions describe only notices codegraphV really sends.** They used to tell agents
  to watch for warnings that only the original TypeScript server prints. They now explain
  `⚠ Pending edits`, `⚠ Index may be stale`, the different-worktree warning and the
  "Did you mean" note.

### Upgrade

```bash
codegraphV upgrade
```

The new instructions reach an agent the next time it starts a session. No re-index is needed.

### Install

```powershell
# Windows
irm https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.ps1 | iex
```

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/UntaDotMy/codegraphV/rust-rewrite/install-rust.sh | sh
```

Then run `codegraphV install`, or `codegraphV migrate` if you used the original codegraph.
In each new project, run `codegraphV init`.

### Known gaps

- The binary is about 74 MB.
- The browser viewer is a preview behind `CODEGRAPHV_UI=1`, and it lacks some of the
  original's views.
- There is no npm package and no JavaScript library API.
- The CLI answers from the index as it is, like the original's CLI. While an agent session
  runs, its server keeps the index current; otherwise run `codegraphV sync` after editing.

Every archive is listed in `SHA256SUMS`.
