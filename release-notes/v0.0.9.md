# codegraphV v0.0.9

### Highlights

- Shorter agent guidance and less duplicate metadata keep more context available for code.
- Filtered searches find matches beyond crowded result limits, and pasted calls search their separate names.
- Named flows retain requested waypoints, and Unicode symbol names work across search, flow and context.
- Qualified names stop matching unrelated similarly named classes.
- Vue, Svelte and Astro no longer lose code after a self-closing script tag.
- Concurrent stale-lock recovery is safer, and a file can be passed as `projectPath`.

Existing indexes remain compatible. Re-index Vue/Svelte/Astro projects to refresh
script and template extraction; search and flow improvements work immediately.

### Fixes

- Missing filename ranges return a clear miss instead of unrelated source.
- Filter-only searches honor pagination; path/name filters preserve literal Unicode substring matching.
- Circular imports are grouped consistently without confusing ordinary calls for import cycles.
- Invalid MCP argument types return a recoverable protocol error.
- Unreadable and newly created empty writer locks are preserved, and Windows permission denial is not mistaken for a dead process.

### Upgrade

```text
codegraphV upgrade
```

Reconnect your agent to load the new guidance. No migration or configuration
rewrite is required for an existing codegraphV installation.

### Audit scope

This release includes tested fixes from the original repository through the
reviewed `f72c9d2e` snapshot. It is **not full parity with that snapshot**:
remaining resolver/framework, CLI, installer-target and viewer changes are
listed in the [audit and upstream ledger](https://github.com/UntaDotMy/codegraphV/blob/v0.0.9/docs/benchmarks/audit-2026-11-03/report.md).
The audit distinguishes measured response size from actual model token usage.

Thanks to the original [CodeGraph](https://github.com/colbymchenry/codegraph)
authors and contributors. Native archives for Windows, Linux and macOS are
verified by the release workflow and listed in `SHA256SUMS`.
