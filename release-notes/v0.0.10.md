# codegraphV v0.0.10

### Highlights

- C and C++ member types follow object-like macro renames, so a `#define sds hisds` header links `hisds` instead of a namesake typedef.
- Objective-C structs and aliases link the types they are declared with, so impact reaches the structs that hold a class.
- Python calls on collection elements link the project method the file can reach, without guessing from the collection's name.
- Rust modules with one file per `#[cfg]` alternative reach the item only one of those files holds, and a `use` through the module reaches it.
- Go interface satisfaction compares method parameter and result types, not only their counts.
- JavaScript files that assign `X.prototype.method` themselves no longer take a lone method guess from another file.
- This release also carries the earlier installer transaction/recovery, shared-guidance, Git-hook, upgrade/migration, bounded graph, MCP cancellation/queue, sparse-checkout and sync invalidation work.

Re-index C, C++, Objective-C, Python, Rust, Go and JavaScript/TypeScript projects
to pick up the resolution changes. Existing indexes remain readable.

### Not included in this release

This is **not full parity** with the reviewed upstream snapshot.

- Swift closure-versus-value overload selection is not ported.
- C# type-argument, keyword-receiver and extension-method rules are preparatory only; behavior is unchanged.
- The remaining resolver-worker, Java, Kotlin, Ruby parameter-flow, framework, installer-target and CLI rows, and the audit release blockers, are listed in the repository's `audit/2026-11-03-overall/progress.md` and `upstream-ledger.md` and in pull request #10.

### Upgrade

```text
codegraphV upgrade
```

Reconnect your agent and re-index the languages above. No migration or
configuration rewrite is required for an existing codegraphV installation.

Thanks to the original [CodeGraph](https://github.com/colbymchenry/codegraph)
authors and contributors. Native archives for Windows, Linux and macOS are
verified by the release workflow and listed in `SHA256SUMS`.
