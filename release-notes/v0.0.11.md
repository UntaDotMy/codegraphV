# codegraphV v0.0.11

### Highlights

- Indexing is fast again. v0.0.10 took about a quarter longer than v0.0.9 to index a large project with a lot of JavaScript or TypeScript; v0.0.11 indexes it about a quarter faster than v0.0.10, is as fast as or faster than v0.0.9 on every project we measured, and uses less memory while it indexes.
- An Intel macOS archive is back. There is no Apple Silicon archive in this release (see "Not included in this release").
- Same index as v0.0.10: the speed fixes add or drop no symbol or link (checked on four projects), so answers keep v0.0.10's accuracy gains over v0.0.9.

Coming from v0.0.10, there is nothing to re-index. Coming from v0.0.9, run `codegraphV index` once per project to pick up v0.0.10's resolution changes.

### Fixes

- JavaScript and TypeScript calls no longer check each receiver for a local declaration before asking whether it is a browser global such as `window` or `document`. Only those globals need the check, and running it on every receiver caused most of v0.0.10's slowdown.
- Finding whether a name is declared locally now reads destructured parameters, like `({ document }) => …`, once per file instead of once per name.
- The pattern matcher keeps one working stack per thread instead of setting one up for every pattern, so indexing builds and discards tens of thousands of patterns more cheaply.
- Patterns that are only tried at a few fixed positions are no longer compiled to machine code, which cost more than it saved.

### Measured

A fresh `codegraphV init`, median of 3 runs, on one Windows 11 machine (6 cores, 12 threads), with each version's Windows build from the release workflow:

| Project | Files | v0.0.9 | v0.0.10 | v0.0.11 |
|---|---:|---:|---:|---:|
| codegraphV (Rust, TypeScript) | 2,043 | 38.3 s | 48.9 s | 37.0 s |
| express (JavaScript) | 149 | 1.75 s | 1.92 s | 1.60 s |
| gin (Go) | 110 | 1.88 s | 1.90 s | 1.83 s |
| MediatR (C#) | 166 | 1.60 s | 1.60 s | 1.60 s |

Peak memory while indexing codegraphV went from 1,658 MB (v0.0.9) and 1,731 MB (v0.0.10) to 1,582 MB. `codegraphV explore` gives the same answers as v0.0.10 on all twelve test queries, byte for byte, and takes about 45 ms per query on codegraphV with all three versions; this release does not change how many tokens an answer uses.

### Not included in this release

- An Apple Silicon (arm64) macOS archive. GitHub's Apple Silicon build machines were too busy to start this release's Mac jobs in four attempts, so the release ships Windows x64, Linux x64 and Intel macOS (x64) archives. The v0.0.11 code passed its full test suite on an Apple Silicon Mac in CI before the release. On an Apple Silicon Mac, `codegraphV upgrade` and the install script look for the arm64 archive, stop with a download error, and leave your installed version in place. To use v0.0.11 there, build it from a checkout of the `v0.0.11` tag with `cargo build --release --locked -p codegraph-cli`. The Intel archive should also run under Rosetta 2, but that has not been tested.

### Upgrade

On Windows, Linux and Intel Macs:

```text
codegraphV upgrade
```

Then reconnect your agent.

Thanks to the original [CodeGraph](https://github.com/colbymchenry/codegraph)
authors and contributors. Native archives for Windows, Linux and Intel macOS
are verified by the release workflow and listed in `SHA256SUMS`.
